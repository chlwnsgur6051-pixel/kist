## Selection notes

- The temporal source set includes the single-output baseline, full-output wrapper, B1 timing intervention, B2 symmetric and teacher-only sources, fixed-input variant, pair-count sweeps, correlation comparator, crosstalk diagnostic, and the original temporal README.
- The copied dataset module is centralized at `legacy/shared/binary_character.py`; `legacy/binary_character.py` preserves the import name expected by unmodified scripts.
- Compact JSON metrics, sweep CSVs, and the existing run log are versioned. Full-output NPY matrices remain available only in the local workspace and are excluded from Git.
- Result versions are stored in distinct destination folders even when their source directory was shared. `pair_count_sweep_v1` corresponds to `summary.json` / `subset_results.csv` / `run.log`; `pair_count_sweep_v2` corresponds to `summary2.json` / `subset_results2.csv`.
- No original source, result, or repository metadata was moved, deleted, or rewritten.
