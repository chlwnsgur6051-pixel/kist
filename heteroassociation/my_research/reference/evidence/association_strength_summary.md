# Association Learning Strength: Static Weighted-Correlation Diagnostics

## Protocol and provenance
10 digit→letter pairs from `binary_character.py` (SHA256 `fed3a90e496a80846bf5b40bf97b3c2434f42c8e75c76a8b21fe9bf2de3df446`), 15-bit bipolar input/output, `W=Σ α_p x_pᵀy_p`, stored-input static recall `score>0` (tie→0). All subsets for K=3,5,7,10: {3: 120, 5: 252, 7: 120, 10: 1}. α grid: (0.01, 0.1, 0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0, 4.0). Every trial changes exactly one α while the others remain 1; no normalization is applied to raw scores. The CSV also records the positive scale `K/Σα` and normalized minimum margin. A common positive scale cannot change predictions. No noise, spike simulation, or parameter fitting was used.

Run from the repository root: `python my_research/experiments/diagnostics/analyze_association_strength.py`. This creates a new timestamped directory and ZIP on each run. The checked-out revision and exact binary patterns are in `config.json`.

## Direct observations
Equal α=1 at K=10 recalled **1/10** associations exactly; bit accuracy 78.00%. K=10 sensitivity has 110 trials; all K values have 27170 trials. The largest K=10 exact count from a *single-coordinate* change on this grid was **3/10**, at digit 6 α=0.01. This is not an optimized joint α vector. Exact count, corrected/newly incorrect bits, newly/lost exact associations and self/other effects for every trial are in `csv/single_strength_sensitivity.csv`; every K=10 output bit before/after is in `csv/k10_output_bit_effects.csv`.

The α=1 association-weighted exact rates are K=3: 64.44%, K=5: 37.78%, K=7: 25.83%, K=10: 10.00%. These reproduce the current pure-correlation reference values.

Input similarity alone does not determine interference direction. The actual recipient-target-signed contribution of source p to recipient q and output j is `dot(x_q,x_p) · y_qj · y_pj`; it is tabulated by pair in `association_pair_factors.csv`. The full exact/bit effects show the trade-off without treating Spearman coefficients as causal. `factor_spearman_correlations.csv` uses tied average ranks; K=3/5/7 rows reuse overlapping subsets and are descriptive, not independent samples. The retrospective preferred α in `k10_factor_effect_comparison.csv` is the smallest α tied for highest *single-change* exact count on the measured grid; it is not a learned rule.

### Measured K=10 examples and factor checks
- Increasing digit 5 from α=1 to 2 yielded 3/10 exact: digits 2-4 became exact. Its own correct-bit count changed by +1, while the other nine together changed by -1; this is a real self/other trade-off despite an exact-count gain.
- Decreasing digit 3 to α=0.1 yielded 3/10 exact, with newly exact digits 2-4. Digit 3 itself changed by -3 correct bits while other memories changed by +3. Lowering a contributor can help others while hurting its own recall.
- Decreasing digit 7 to α=0.5 caused the sole initially exact digit 7 to fail, leaving 0/10 exact. Therefore lowering α is not uniformly beneficial.
- For α=0.5 versus α=1, Spearman ρ between *mean absolute input dot* and total exact-count change is +0.744; for *negative signed interference caused*, it is +0.809 (n=10, many tied exact counts). Input similarity by itself omits the target sign. The mean input-dot × target-dot factor gives ρ=+0.382 for this outcome; in this small K=10 comparison it does **not** provide stronger rank association. Per-bit signed contributions remain the direct evidence.
- Baseline incorrect-bit count versus α=2 total exact change gives ρ=+0.171. Digit 5 α=2 improves one own bit but digit 5 remains inexact, so strengthening a difficult memory does not imply its exact recovery.

## Archived MILP references
Validated both bipolar arrays and two alpha vectors in association_alpha_milp_reference_20261019.zip (SHA256 e0e81c7d9162c87eeba73276e6758be205a02fc3544d460eec77f4ed57965f0c). The archive contains no [0.5,3.0] optimum. The archived MILP vector reproduced 6/10 exact (85.33% bits), with exact digits 0-1-2-6-7-9 and minimum margin among those six 9.9993e-05. The archived six-preserving margin vector also reproduced 6/10 exact (85.33% bits), with minimum margin among its exact digits 1.38902. These distinct vectors achieve the same observed 6/10 exact count but have different margins; they provide two documented 6/10 references, not proof of uniqueness or generalization. Both put digit 3 and digit 4 at α=0.01; whether this commonality persists across *all* optimal solutions is untested. The requested [0.5,3.0] solution is not in the provided archive and was not invented. These α vectors use all targets and are diagnostic references, not STDP learning results. `csv/archived_solution_summary.csv` and `csv/archived_solution_factors.csv` contain their evaluated results. An additional archived vector can be passed as a JSON list of `{"label": "...", "alpha": [10 positive values in digit order]}` with `--solutions`.

In both archived vectors digit 0 has α>2 although its equal-strength negative interference magnitude is 412; digit 8 causes the largest equal-strength negative interference (606) and has α≈0.34/0.63. Thus a simple rule of decreasing α whenever one interference factor is large does not explain the joint solutions. The two archived vectors differ notably at digit 5 (α≈0.734 versus 0.01) while retaining the same six exact memories. These are observed patterns in two target-informed solutions, not a unique prescription.

## STDP information availability and feasibility
- **A — directly synapse-local:** current weight, pre/post event timing and local update history. These can support local magnitude modulation, but the global association factors measured here are not available from one synapse alone.
- **B — same-network population activity:** output firing and aggregate activity may provide a proxy for current recall response. Computing association-level difficulty or weak-margin signals would require identification of the presented association and an activity/error interpretation; this experiment did not implement that circuitry.
- **C — global target/dataset information:** pairwise input/target similarity matrices, exact recall of every memory, signed margins against all target bits, cross-memory interference and MILP α. These require information across associations and/or correct targets; they are not local STDP observables.

This analysis proposes no new rule and establishes no biological feasibility. `figures/optimal_alpha_vs_characteristics.png` plots archived vectors when available and explicitly marks their absence otherwise. K=10 n=10 and discrete exact counts limit factor inference; no causal claim is made. All numeric outputs and the executable script are included in the ZIP.
