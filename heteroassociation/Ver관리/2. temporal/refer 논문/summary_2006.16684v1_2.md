# Spiking Associative Memory For Spatio-Temporal Patterns 요약

## 1. 풀고자 하는 문제
* 기존 스파이킹 신경망(SNN)에서 생물학적 학습 규칙인 STDP(Spike Time-Dependent Plasticity)를 사용할 때, 새로운 정보가 입력되거나 배경 노이즈가 발생하면 기존에 저장된 메모리가 너무 빨리 지워져 버리는 문제(안정성-가소성 딜레마)가 있었습니다.
* 정밀한 스파이크 타이밍을 기반으로 하는 신뢰할 수 있는 정보 표현, 연산 및 학습 원리가 부족하여 복잡한 신경망 시스템을 설계하는 데 어려움이 있었습니다.

## 2. 접근법
* 지터(시간적 흔들림)나 배경 노이즈가 있는 환경에서도 정밀한 스파이크 타이밍으로 인코딩된 패턴을 추출하고 학습할 수 있는 **'순환 STDP(Cyclic STDP)'**라는 단순한 확률적 학습 규칙을 제안했습니다.
* 상관 행렬 메모리(CMM)의 철학을 시간 도메인으로 확장한 **'Cyclic N-of-M 인코딩'**이라는 희소(sparse) 고정 가중치 표현 방식을 도입했습니다.
* 학습된 시냅스 가중치가 다른 패턴 학습 과정이나 노이즈에 의해 변형되는 것을 막고 정확한 타이밍을 유지하기 위해, 가중치를 고정시키는 **'잠금 비트(Lock bit)'** 개념과 **'시냅스 억제(Synaptic depression)'**를 통한 항상성 유지 메커니즘을 도입했습니다.

## 3. 인풋과 아웃풋
* **인풋:** 3,200개의 입력 뉴런 층을 통해 전달되는 주기적인 시공간 패턴(Key 역할을 하는 Cyclic N-of-M 패턴)입니다.
* **아웃풋:** 3,200개의 출력(메모리) 뉴런 집단이 입력 패턴(Key)과 연관되어 미리 학습된 정확한 타이밍에 생성해내는 타겟 시공간 패턴(Data)입니다.

## 4. 템퍼럴 코딩이 적용된 방식
* 스파이크 발생 빈도(Rate)가 아닌 개별 스파이크의 **'정확한 발생 시간(Precise time)'** 자체에 정보를 담는 방식을 채택했습니다.
* **'Cyclic N-of-M 인코딩'**을 통해 시간 축을 이산적인 시간 빈(time bin)으로 나누고, 고정된 주기(Cycle time, T) 내에서 전체 M개의 뉴런 중 정확히 N개의 뉴런만이 한 번씩 특정 시간 빈에 스파이크를 발생시키도록 시공간 패턴을 구성했습니다.

## 5. 결과
* 3,200개의 입력 뉴런과 3,200개의 출력 뉴런으로 구성된 단일 계층 연관 메모리 시뮬레이션 결과, 제안된 학습 규칙을 통해 뉴런들이 노이즈 환경에서도 여러 패턴 쌍을 안정적으로 단기 기억(Short-term memory)으로 저장하고 회상할 수 있음을 입증했습니다.
* 단일 뉴런이 30개의 패턴에 대해 정확한 타이밍의 출력 스파이크를 생성하도록 학습하는 데 성공했으며, 이를 전체 네트워크로 확장할 경우 약 1,260개의 시공간 패턴 연관성을 빠르고 신뢰성 있게 저장 및 복원할 수 있을 것으로 추산되었습니다.
