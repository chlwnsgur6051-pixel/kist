# KIST Work Projects

This repository collects project work in this workspace.

## Projects

- [`heteroassociation/`](heteroassociation/README.md): STDP-based hetero-associative memory research with spiking neural networks. Research history and procedures are documented in `heteroassociation/my_research/`.
- [`qwen_lora_benchmark/`](qwen_lora_benchmark/README.md): GPU memory and throughput benchmark for Qwen causal language models using LoRA on the Databricks Dolly dataset.

Each project keeps its own source, results, and run documentation. Historical failures are retained with successful runs.
